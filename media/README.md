# Media

Drop your preview video / loop in this folder. Suggested:

- `loop.mp4` — short looping highlight reel (silent, ~10–20s, MP4 H.264)
- `walkthrough.mp4` — longer narrated walkthrough (optional)

Once in place, link it from the top of the root `README.md`:

```markdown
https://github.com/<your-user>/WhatsTheScore-Preview/raw/main/media/loop.mp4
```

GitHub auto-embeds video files referenced as raw URLs in the README.

A few tips:
- Keep `loop.mp4` under ~10 MB so it loads fast on the README.
- For higher-quality assets (App Store hero video, large MP4s), upload to a release or use Git LFS rather than committing to `main`.
